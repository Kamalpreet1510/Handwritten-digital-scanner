WRITESCAN AI - RUN GUIDE

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:
   pip install -r requirements.txt
4. Then:
   python app.py
5. Open:
   http://127.0.0.1:5000

NOTE:
The website UI, image upload, preview, backend endpoint, copy and download features are included.
For actual handwriting-to-text recognition, connect an OCR engine or your trained CNN model inside /upload in app.py.
